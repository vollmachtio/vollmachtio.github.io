A small permission. A precise purpose.

A mandate,
not a blank check.

A Human Mandate is intended to bind an agent to a specific action, resource and set of limits. The enforcement layer checks that authority before acting.

Vollmacht is German for authority to act on someone else’s behalf. That is the idea: delegated authority, not unrestricted access.

Designed for meaningful oversight

Less interruption.
More intentional approval.

No prompt for every step.

Repeated prompts invite reflexive approval. The goal is to ask at selected consequential boundaries, not turn every tool call into a biometric ceremony.

Your biometrics stay local.

Passkeys use Touch ID or another supported verification method. Vollmacht does not need your fingerprint. User verification is not proof of humanity or proof that you understood a request.

Enforcement matters.

A mandate only helps when consequential actions pass through a trusted enforcement layer. It cannot stop an agent that can bypass that layer with its own credentials.

Where we are today

A working direction.
Not a production promise.

Vollmacht is in experimental development. These examples describe the intended experience, not shipped integrations.

Do not use it as the sole control for production-critical operations. Protocol design, interoperability and security evaluation are ongoing.
